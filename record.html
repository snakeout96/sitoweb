I Resource Record

Link:

I name server contengono una tabella con tre colonne: NOME, TYPE, VALORE. Ogni riga si chiama Resource Record (RR).

Request e response

Nel nostro schema intuitivo la request è un RR incompleto (nome e type con un punto interrogativo) e la response è l'RR completo:

www.units.it A ?
www.units.it A IP1

La response può anche dire che l'RR non esiste: nel gergo DNS si chiama NXDOMAIN (no such domain, anche se in realtà dovrebbe essere «no such RR»).

I principali type

Type Nome Valore Esempio
A nome di un host indirizzo IP mail.virgilio.it → 192.113.21.27
MX nome di un dominio di email nome dell'host mail server units.it → mx.units.it
CNAME nome di un host nome equivalente sitoweb.com → snakeout96.github.io
