01 / IL VIAGGIO DEI DATI

Come funziona Internet?

Dietro una semplice richiesta del browser si nasconde una conversazione tra computer, server e router, regolata da protocolli condivisi.

Segui il percorso ↓

DAL BROWSER AL SERVER

Una richiesta, più passaggi

Quando digiti un indirizzo, il dispositivo deve individuare il server corretto e poi scambiare con esso i dati necessari.

01

Il nome diventa un indirizzo

Il DNS (Domain Name System) associa un nome, come esempio.it, a un indirizzo IP che identifica il server nella rete.

DNS
02

La richiesta raggiunge il server

Il browser invia una richiesta usando un protocollo applicativo, per esempio HTTP o la sua versione protetta HTTPS.

HTTP(S)
03

I dati viaggiano in pacchetti

Le informazioni vengono suddivise in unità più piccole. I pacchetti attraversano la rete e possono seguire percorsi differenti.

IP
04

Il browser ricostruisce la pagina

Il server risponde e il browser interpreta HTML, CSS, JavaScript e le altre risorse per mostrare il contenuto.

WEB

IL CONCETTO CHIAVE

Internet è un'infrastruttura condivisa.

Non esiste un unico computer che contiene tutta la rete: sistemi autonomi e dispositivi diversi comunicano grazie a standard e protocolli comuni.
